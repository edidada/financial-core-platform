# 04 一致性

- `../consistency.md`：不变量清单、并发扣款、原子提交、故障恢复矩阵、校验 SQL。
- ADR-0003（单库事务边界）、ADR-0005（幂等三要素）、ADR-0007（Outbox 至少一次 + 消费侧去重）。

## 阶段二一致性模型升级

| 边界 | 阶段一 | 阶段二 |
| --- | --- | --- |
| 写入 | 单库本地事务 | 单库本地事务 + Outbox 同事务 |
| 跨服务 | 无 | 本地事务 + Outbox + 消费幂等（不采用 XA/TCC 强跨库事务） |
| 消息 | 不承诺恰好一次 | 至少一次投递 + 消费侧 `message_key` 去重 |
| 恢复 | 状态机补状态 | 追加 Outbox 重放 + 多方对账核对 |
