# 性能报告

> 完整报告见 `benchmark/reports/performance-report.md`（含压测矩阵模板）。
> 本文件为文档体系入口，对应 `README.txt` 第八节文档清单与第十节「成果 B」。

## 状态

- **已验证**：正确性基线（并发扣款、幂等、冲正、不变量 I-1~I-4）。
- **待测**：5,000 TPS、P99 延迟、GC、火焰图、SQL 执行计划、72 小时稳定性。
- 分阶段指标是工程验收目标，不是对一线企业内部生产指标的推断。

## 正确性基线（本机实测）

| 项 | 结果 |
| --- | --- |
| 环境 | Windows 11 / JDK 21.0.9 / MySQL 8.4.8 / Spring Boot 3.3.5 / 单实例 |
| 单账户并发扣款 | 30 并发，10,000 分账户每笔扣 8,000 分 → 恰好 1 笔成功，余额 2,000 分 |
| 幂等重放 | 同一 `Idempotency-Key` 返回同一交易号，无重复扣款 |
| 冲正 | 净额归零，反向分录可追溯 |
| 不变量 | 每步 `I-1~I-4` 全 0，`healthy=true` |

## 结论纪律

所有性能结论必须在**固定硬件、真实业务混合、指定数据规模、稳定负载**下验证，并记录完整环境参数。
禁止预设 5,000 TPS / 亿级数据处理目标可达；必须结合硬件与数据分布调整。
