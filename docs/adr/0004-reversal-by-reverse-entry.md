# ADR-0004：冲正通过反向分录实现，不删除或修改已生效分录

- 状态：Accepted
- 日期：2026-11-14
- 相关：`accounting-design.md` 第七节、`README.txt` 4.1

## 背景

账务错误需要纠正。可选做法：直接 UPDATE 金额、物理 DELETE 分录、或生成反向分录。金融账务要求可追溯、可审计、不可抵赖。

## 决策

- 已生效分录 **只追加（INSERT-only）**，不提供 UPDATE / DELETE 接口与授权。
- 冲正生成一张 **反向凭证**：借贷方向与金额相同、方向相反，并双向关联：
  - 反向凭证 `reversal_of = 原 journal_id`
  - 原凭证 `reversed_by = 反向 journal_id`
- 冲正本身是一次独立交易，走完整状态机与幂等控制，原交易状态 `SUCCEEDED → REVERSED`。
- 净额为 0，两张凭证均完整保留，满足 I-6 与审计追溯。
- 禁止对已冲正凭证二次冲正；禁止对 FAILED / 未入账交易冲正。

## 备选方案

| 方案 | 否决原因 |
| --- | --- |
| 物理删除原分录 | 账务记录不可追溯，违反监管与审计要求 |
| 直接 UPDATE 金额/方向 | 破坏不可变性，历史余额无法重算 |
| 负数金额冲销 | 破坏 `amount_minor > 0` 约束与借贷语义，易混淆 |

## 后果

**正面**
- 任何时候都能重放历史分录得到正确余额，`余额 = 分录累计` (I-2) 恒成立。
- 满足 I-5（不可改删）与 I-6（净额 0、可追溯）。
- 与监管审计、事后对账天然兼容。

**负面 / 代价**
- 数据量随冲正增长（阶段三用分区与归档处理）。
- 查询「当前有效余额」需包含反向分录，不能只看原凭证；余额表作为读优化冗余承担该职责。
- 冲正权限必须严格管控，避免滥用（审计日志记录操作者与原因）。

## 验证

`test-strategy.md` TC-6：冲正后 I-1~I-6 全部成立，两张凭证可双向追溯。
